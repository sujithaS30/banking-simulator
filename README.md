🏦 Banking Simulator
📖 Overview

Banking Simulator is a Java-based application designed to simulate core banking operations such as account creation, account management, and basic transaction processing. The project demonstrates backend development using Java and Maven, along with a simple frontend built using HTML, CSS, and JavaScript.

This project was developed to strengthen understanding of software development fundamentals, including Object-Oriented Programming (OOP), project structuring, and frontend–backend interaction.

🎯 Objectives

Simulate real-world banking operations in a simplified environment

Demonstrate Java backend development concepts

Implement structured project development using Maven

Practice integrating frontend UI with backend logic

Strengthen GitHub project management and documentation skills

⚙️ Installation & Setup
✅ Prerequisites

Ensure the following are installed on your system:

Java JDK (Version 8 or higher)

Maven

Git

Any IDE (IntelliJ IDEA / Eclipse / VS Code)

📥 Clone the Repository
git clone https://github.com/sujithaS30/banking-simulator.git

📂 Navigate to Project Folder
cd banking-simulator

🔨 Build the Project
mvn clean install

▶️ Run the Application

Run the project using your IDE or execute the main class if configured.
